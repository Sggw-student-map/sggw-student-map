# Aplikacja studentów dla studentów - app  for students from students

Dostępna pod  https://maciek-studia-test-2026.web.app/login


## Miejsca okolic SGGW - have fun in Warsaw


SGGW Student Map to interaktywna platforma stworzona przez studentów dla studentów, której celem jest ułatwienie aklimatyzacji w tętniącym życiem kampusie SGGW oraz integracja lokalnej społeczności. 
Aplikacja nie tylko pomaga w błyskawicznym odnajdywaniu kluczowych punktów na mapie Warszawy i okolic uczelni, ale przede wszystkim stanowi przestrzeń do wymiany doświadczeń, opinii oraz budowania unikalnej sieci studenckich kontaktów.

SGGW Student Map is an interactive, community-driven platform built by students for students to help newcomers seamlessly navigate the vibrant SGGW campus and blend into university life. Beyond simply locating key spots around Warsaw and the campus, the app serves as a social hub where students can share reviews, exchange experiences, and foster meaningful connections within the academic community.



## 🛠️ Stos technologiczny / Tech Stack

### Frontend
* **Angular**  – Główna biblioteka interfejsu użytkownika / Core UI library.
* **Tailwind CSS**  – Stylowanie i nowoczesny design / Styling and modern UI layout.
* **Google Maps API** – Integracja interaktywnej mapy / Interactive map integration.

### Backend & Database
* **Firebase Suite** (Auth, Firestore) – Bezpieczna autoryzacja użytkowników oraz baza danych w czasie rzeczywistym / Secure authentication and real-time database.


### Hosting & Tools
* **Firebase Hosting** – Szybkie i stabilne wdrażanie aplikacji / Fast and stable application deployment.
* **Git & GitHub** – Kontrola wersji i współpraca / Version control and collaboration.
