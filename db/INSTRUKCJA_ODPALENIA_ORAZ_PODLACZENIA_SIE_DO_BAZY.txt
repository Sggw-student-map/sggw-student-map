Oczywiscie kazdy musi miec zainstalowanego Dockera.

=== URUCHOMIENIE BAZY DANYCH ===

1) Otwórz terminal w folderze /db

2) Uruchom kontener jedną komendą:

   docker compose up -d

3) Sprawdź czy działa:

   docker compose ps

   lub w Docker Desktop w zakładce Containers powinien być widoczny
   kontener "sggw-student-map-db-container" ze statusem "running".

=== DANE POŁĄCZENIA ===

Host:     localhost
Port:     5432
Database: sggw_student_map
User:     postgres
Password: postgres

=== PODŁĄCZENIE DO BAZY (DBeaver / DataGrip / psql) ===

New Database Connection -> PostgreSQL
Wpisz dane połączenia z sekcji powyżej -> Test Connection

=== ZATRZYMANIE KONTENERA ===

   docker compose down

Uwaga: dane bazy są zachowane po zatrzymaniu (volume).
Jeśli chcesz wyczyścić bazę całkowicie (np. zresetować schemat):

   docker compose down -v
   docker compose up -d
